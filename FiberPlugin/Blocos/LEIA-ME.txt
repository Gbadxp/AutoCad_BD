BIBLIOTECA DE BLOCOS DO FIBER PLUGIN
====================================

Todos os blocos do plugin ficam dentro do arquivo BLOCOS.dwg, nesta pasta.
O plugin oferece SOMENTE os blocos definidos nele: para acrescentar, alterar ou
remover um bloco do plugin, basta editar o BLOCOS.dwg e salvar.

Quando um comando precisa de um bloco que ainda não está no desenho, o plugin copia
a definição do BLOCOS.dwg automaticamente, sem precisar de template.
Se o desenho já tiver um bloco com o mesmo nome (ex.: de um template antigo), ele é
substituído pela versão do BLOCOS.dwg, e os blocos já inseridos ficam com o desenho novo.

COMO ACRESCENTAR BLOCOS
-----------------------
- Abra o BLOCOS.dwg, crie ou cole o bloco (comando BLOCO) e salve. No AutoCAD, clique em
  Atualizar Blocos (aba Fibra): na primeira vez, escolha este BLOCOS.dwg; daí em diante o
  plugin lê direto dele, sem precisar rodar o build.ps1 nem reinstalar; ou
- Com um projeto aberto, rode FIBRA_EXPORTAR_BLOCOS: os blocos daquele desenho são
  copiados para dentro do BLOCOS.dwg (a versão anterior fica salva como BLOCOS.bak).

GRUPOS E COMANDOS
-----------------
O grupo de cada bloco vem do nome e define qual comando o insere:
  Inserir Postes   -> nomes com POSTE (DT e CC: veja abaixo)
  Inserir CTO      -> nomes com CTO
  Inserir CEO      -> nomes com CEO (ex.: CEO_1, CEO_2)
  Elétricos        -> TRAFO, CHAVE, PARA-RAIO, ATERRAMENTO, TRANSFORMADOR, LUMINARIA
  Amarração        -> nomes com AMARRAÇÃO / AMARRACAO
  Outros Blocos    -> o restante

POSTES DT E CC
--------------
O FIBRA_INSERIR_POSTE usa um bloco para cada tipo de poste. O plugin encontra os blocos
pelo nome, nesta ordem: exatamente "DT" / "CC"; nomes com DT ou CC como palavra
(ex.: "POSTE DT"); ou "DUPLO T" / "CIRCULAR".

REGRAS DOS ATRIBUTOS
--------------------
Postes: precisam ter "POSTE" no nome e um atributo NUMERO (ou NÚMERO / ID).
        O atributo NOME (ou TIPO / INFO / DESCRICAO) guarda o tipo do poste,
        ex.: "DT 11/200". O número após a barra é o esforço nominal em daN (norma),
        que o plugin converte para kgf (200 daN = 204 kgf) para validar o esforço.
Seta de esforço: se existir um bloco "SETA DE ESFORÇO", ele é usado, com os atributos
        ESFORCO_KFG (valor) e ANGULO. Sem ele, o plugin desenha a seta sozinho.
Qualquer bloco: COORDENADA_X / COORDENADA_Y são preenchidos na inserção.
