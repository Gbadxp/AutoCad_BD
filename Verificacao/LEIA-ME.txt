FIBER PLUGIN - VERIFICAÇÃO DO COMPUTADOR
=========================================

Para que serve
  Confere se o computador tem tudo o que o Fiber Plugin precisa e, se faltar
  algo, pergunta se você quer instalar.

Como usar
  Clique duas vezes em Verificar.bat.
  (ou no PowerShell: .erificar.ps1)

O que é verificado
  Para usar o plugin:
    - Windows 64 bits
    - AutoCAD 2022, 2023, 2024, 2025 ou 2026
    - .NET Framework 4.8 ............ usado no AutoCAD 2022 a 2024
    - .NET 8 Desktop Runtime ........ usado no AutoCAD 2025 e 2026
    - Fiber Plugin instalado e na versão mais nova da pasta Instalador
  Para editar e compilar o código (o script pergunta se quer verificar):
    - .NET SDK 8 ou mais novo
    - Git

Como instala o que falta
  - .NET e Git: pelo winget (instalador de programas do Windows). Sem winget,
    abre a página de download.
  - Fiber Plugin: pelo instalador Instalador\FiberPlugin-<versão>.msi deste
    repositório (feche o AutoCAD antes).
  - AutoCAD: não é instalado pelo script; instale pela sua conta Autodesk.
  O Windows pode pedir permissão de administrador durante as instalações.

Opções (PowerShell)
  .erificar.ps1 -SomenteVerificar     Só mostra o resultado, sem instalar nada.
  .erificar.ps1 -Desenvolvimento      Inclui .NET SDK e Git sem perguntar.
